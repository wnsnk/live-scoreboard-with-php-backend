## Installation
- clone the repository:
```bash
git clone https://github.com/wnsnk/live-scoreboard-with-php-backend.git
```

## Usage
- run the app:

```bash

cd live-scoreboard-with-php-backend
php -S localhost:8000
```

php will start a local server where the app is hosted.
- in your webbrowser go to: http://127.0.0.1:8000
